# 실습 문제(PostgreSQL)

## A. 기본 SELECT 문제 (10)

**Q1** 전체 고객을 가입일 최신순으로 조회하라.

**Q2** ACTIVE 상태 고객의 이름과 이메일을 조회하라.

**Q3** 최근 7일 이내 가입한 고객을 조회하라.

**Q4** 재고가 20 이하인 상품을 재고 오름차순으로 조회하라.

**Q5** 상품 카테고리별 상품 개수를 조회하라.

**Q6** 주문 상태별 주문 건수를 조회하라.

**Q7** 최근 14일 주문을 조회하라.

**Q8** 주문 금액 상위 3건을 조회하라.

**Q9** 결제 상태가 PAID인 결제만 조회하라.

**Q10** 결제 생성일 기준 최신 결제를 조회하라.

---

## B. JOIN 문제 (10)

**Q11** 주문과 고객명을 함께 조회하라.

**Q12** 주문과 결제 상태를 함께 조회하라(결제 없는 주문 포함).

**Q13** 주문별 상품명과 수량을 조회하라.

**Q14** 주문별 주문 라인 수를 조회하라.

**Q15** 고객별 주문 건수를 조회하라.

**Q16** 결제 완료 주문의 고객명과 주문 금액을 조회하라.

**Q17** 결제된 주문 기준 카테고리별 매출을 조회하라.

**Q18** 고객 ID 3의 주문 상품을 조회하라.

**Q19** 결제가 없는 주문을 조회하라.

**Q20** 상품별 총 판매 수량을 조회하라(결제 완료 기준).

---

## C. 함수 / 표현식 문제 (10)

**Q21** 주문일시에서 날짜만 추출하라.

**Q22** 결제 시각이 없으면 `N/A`로 표시하라.

**Q23** 상품명 길이를 조회하라.

**Q24** 고객 이메일에서 도메인만 추출하라.

**Q25** 주문일시를 `YYYY-MM` 형식으로 출력하라.

**Q26** 주문 금액을 만원 단위로 반올림하라.

**Q27** 주문 상태를 대문자로 출력하라.

**Q28** 상품 가격을 HIGH/MID/LOW로 구분하라.

**Q29** 상품 재고 상태를 SOLD\_OUT/LOW/OK로 구분하라.

**Q30** 최근 7일 주문 여부를 true/false로 표시하라.

---

## D. 트랜잭션 문제 (5)

**Q31** 재고를 1 감소시킨 뒤 ROLLBACK 하라.

**Q32** 재고를 1 감소시키고 COMMIT 하라.

**Q33** 신규 주문을 생성하고 order\_id를 확인하라.

**Q34** 주문에 상품 1개를 추가하고 총액을 갱신하라.

**Q35** 결제를 생성하고 주문 상태를 PAID로 변경하라.

---

## E. VIEW 문제 (5)

**Q36** 주문 + 고객 + 상품 정보를 포함한 VIEW를 생성하라.

**Q37** 해당 VIEW에서 주문 ID 1003만 조회하라.

**Q38** VIEW를 이용해 고객별 매출 합계를 조회하라.

**Q39** VIEW를 이용해 결제 완료 주문만 조회하라.

**Q40** VIEW를 이용해 카테고리별 매출을 조회하라.
