## 2. 시스템 구성 요소별 역할 설명

### VM 구성

| VM | IP | 역할 |
| --- | --- | --- |
| VM1 | 192.168.80.110 | Web UI + API + 수집기 |
| VM2 | 192.168.80.120 | MySQL, Redis |
| VM3 | 192.168.80.130 | PostgreSQL, MongoDB |

---

### 데이터 흐름 관점에서 본 역할

### 1️⃣ Frontend (브라우저)

* 사용자는 **웹 화면만 사용**

* 직접 DB에 접근 ❌

* 모든 요청은 **VM1(Node API)** 로 전달

하는 일:

* 서버 목록 보기

* 현재 상태 보기

* 이벤트 로그 보기

* 설정 변경 요청 보내기

👉 **Frontend는 “제어판”일 뿐, 판단은 하지 않음**

---

### 2️⃣ VM1 – Node.js (API 서버)

VM1은 **모든 것을 연결하는 중간 관리자 역할**.

하는 일:

* Frontend 요청 수신

* DB별 조회/저장 중계

* 주기적으로 서버 상태 수집

* 임계치 초과 여부 판단

---

### 3️⃣ MySQL – 서버 자산 정보 (정형 데이터)

저장하는 것:

* 서버 목록

* IP

* 환경(dev/prod)

* 활성화 여부

특징:

* 자주 안 바뀜

* 틀리면 안 됨

* 관계형 구조 적합

👉 **“서버 대장”**

---

### 4️⃣ Redis – 현재 상태 / 휘발성 데이터

저장하는 것:

* 현재 CPU/메모리 값

* TTL 있는 상태 정보

특징:

* 계속 바뀜

* 없어져도 됨

* 빠른 접근 필요

👉 **“지금 이 순간 상태”**

---

### 5️⃣ MongoDB – 설정 정보 (유연한 문서)

저장하는 것:

* 임계치(cpu, mem 등)

* 쿨다운 시간

* 태그

특징:

* 구조 자주 변경

* 필드 추가 자유

* 설정 성격

👉 **“운영 정책 문서”**

---

### 6️⃣ PostgreSQL – 이벤트 로그 (JSONB)

저장하는 것:

* CPU 초과 이벤트

* 언제, 왜 발생했는지

* 당시 설정/값(JSONB)

특징:

* 삭제하지 않음

* 분석 대상

* 과거 이력

👉 **“감사/분석 로그”**

---

## 3. Frontend 포함 전체 흐름 정리

### CPU 임계치 초과 상황 예시

```
1. Node가 주기적으로 서버 상태 수집
2. Redis에 현재 CPU 저장 (TTL)
3. MongoDB 설정에서 임계치 조회
4. 초과 판단
5. PostgreSQL에 이벤트 기록
6. Frontend에서 이벤트 로그 조회
```

👉 **Frontend는 판단하지 않고, 결과만 본다**

### 실습 2️⃣ Redis – TTL 체감

VM2에서:

```
redis-cli GET m:192.168.80.110
redis-cli TTL m:192.168.80.110
```

관찰:

* TTL 감소

* 일정 시간 후 삭제

* 다시 수집되면 재생성

✍️ 서술

> 이 데이터를 PostgreSQL에 저장하지 않는 이유는?

---

### 실습 3️⃣ MongoDB – 설정 변경으로 동작 제어

VM3에서:

```
use mon
db.configs.updateOne(
  { serverIp: "192.168.80.110" },
  { $set: { "thresholds.cpu": 20 } }
)
```

관찰:

* 코드 수정 ❌

* 재시작 ❌

* 이벤트 발생 패턴 변화 ⭕

✍️ 서술

> 설정과 코드가 분리되어 있을 때의 장점은?

---

### 실습 4️⃣ PostgreSQL – 이벤트 분석

```
SELECT
  metric,
  level,
  data->>'threshold' AS threshold,
  data->>'value' AS value,
  created_at
FROM events
ORDER BY event_id DESC
LIMIT 10;
```

관찰:

* JSONB에 당시 상황 저장

* 이벤트는 사라지지 않음

✍️ 서술

> 이 데이터를 Redis에 두면 안 되는 이유는?
