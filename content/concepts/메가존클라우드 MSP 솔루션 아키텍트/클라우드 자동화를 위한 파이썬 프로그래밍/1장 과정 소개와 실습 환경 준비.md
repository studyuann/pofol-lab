# 1장. 과정 소개와 실습 환경 준비

## 1.1 과정 소개

Python을 사용해 AWS 리소스를 조회하고 제어하는 자동화 스크립트를 다루고, 생성형 AI를 활용해 코드 초안을 만들고 수정하는 방식으로 실습을 진행한다.

실제 자동화 시나리오를 기준으로 코드를 생성하고 실행하고 수정하는 흐름으로 진행한다.

---

## 1.2 과정 내용

### Python 기초 문법

자동화 코드를 이해하고 수정하는 데 필요한 Python 문법을 학습한다.

### boto3와 AWS API 자동화

Python에서 boto3를 사용해 AWS 서비스를 조회하고 제어하는 방법을 학습한다.

### 운영,보안 점검 자동화

IAM 사용자와 정책을 조회하고, 운영 점검에 활용할 수 있는 기본 자동화 코드를 다룬다.

### 로그 분석 자동화

텍스트 로그와 JSON 로그를 읽고, 조건 검색과 집계를 수행하는 자동화 코드를 실습한다.

### Amazon Bedrock 기반 AI 자동화

로그 분석 결과를 요약하거나 운영 보고 문장을 생성하는 형태의 AI 자동화를 실습한다.

### 운영 정보 및 상태정보 기반 질의응답 챗봇

사전에 준비한 운영 가이드와 FAQ를 기반으로 질문에 답하는 챗봇을 구현한다.

---

## 1.3 학습 방식

이 과정은 **생성형 AI 협업형 실습 방식**으로 진행한다.

기본적인 흐름은 다음과 같다.

1. 자동화할 작업을 정리한다.

2. 생성형 AI에게 코드 초안을 요청한다.

3. 생성된 코드를 읽고 구조를 파악한다.

4. 필요한 부분을 수정한다.

5. 코드를 실행한다.

6. 오류가 발생하면 원인을 확인하고 다시 수정한다.

7. 최종적으로 동작하는 자동화 코드로 정리한다.

이 방식에서는 다음 능력이 중요하다.

* 요구사항을 구체적으로 설명하는 능력

* 생성된 코드를 읽는 능력

* 오류 메시지를 보고 수정하는 능력

* AWS 환경에 맞게 코드를 조정하는 능력

## 1.4 실습 환경 준비

이 과정에서 사용할 기본 환경은 다음과 같다.

* Python

* pip

* venv(필요시)

* 코드 편집기(vscode)

* AWS CLI

* AWS CLI Profile

* 실습용 AWS 계정

### Python

이 과정의 기본 언어이다.

boto3 자동화, 로그 분석, Bedrock 호출, 챗봇 구현 모두 Python으로 실습한다.

### pip

Python 패키지를 설치하는 도구이다.

`boto3` 같은 라이브러리를 설치할 때 사용한다.

### venv

프로젝트별 독립된 Python 환경을 만들기 위한 기능이다.

패키지 충돌을 줄이고 실습 환경을 일정하게 유지하는 데 사용한다.

### AWS CLI

AWS 인증 상태를 확인하고, 프로필 기반 로그인 세션을 생성하는 데 사용한다.

### AWS CLI Profile

프로필은 AWS CLI와 SDK가 사용할 인증/설정 단위를 의미한다.

실습에서는 지정한 프로필로 로그인하고, 해당 프로필의 임시 자격 증명을 사용해 boto3 코드와 CLI 명령을 실행한다. `--profile` 옵션으로 특정 프로필을 지정해 사용할 수 있다.

## 1.5 실습 환경 점검 항목

실습 전 다음 항목을 확인한다.

### 1) Python 설치 확인 : 설치된 버전 확인(python, python3, python3.12 등)

```
python --version
```

또는

```
python3 --version
```

### 2) pip 설치 확인

```
pip --version
```

### 3) 실습 폴더 생성

```
mkdir aws-auto-python
cd aws-auto-python
```

### 4) 가상환경 생성

```
sudo apt install python3-venv
python3 -m venv venv
```

### 5) 가상환경 활성화

### macOS / Linux

```
source venv/bin/activate
```

### 6) boto3 설치

```
pip install boto3
```

### 7) AWS CLI 확인

```
aws --version
```

`aws login` 명령은 AWS CLI 2.32.0 이상에서 사용할 수 있으므로, 버전 확인이 필요하다. ([AWS 문서](https://docs.aws.amazon.com/cli/latest/userguide/cli-configure-sign-in?utm_source=chatgpt.com))

### 8) 프로필 로그인

실습에서 사용할 프로필로 로그인한다.

```
aws login --profile lab
```

`aws login`은 브라우저 기반 인증 흐름 또는 기존 콘솔 세션을 사용해 로그인할 수 있고, 로그인 후 임시 자격 증명이 자동 생성된다. 또한 이 자격 증명은 AWS CLI와 다른 AWS SDK/도구에서 사용할 수 있다.

### 9) 로그인 후 프로필 지정 명령 예시

프로필을 지정해 AWS 명령을 실행할 수 있다.

```
aws sts get-caller-identity --profile lab
```

프로필은 CLI 명령에서 `--profile` 옵션으로 지정해 사용할 수 있다.

### 10) boto3에서 프로필 사용 예시

`boto3`도 세션에 프로필을 지정해 사용할 수 있다.

```
import boto3

session = boto3.Session(profile_name="lab")
ec2 = session.client("ec2", region_name="ap-northeast-2")

print(ec2.describe_regions()["Regions"][0]["RegionName"])
```
