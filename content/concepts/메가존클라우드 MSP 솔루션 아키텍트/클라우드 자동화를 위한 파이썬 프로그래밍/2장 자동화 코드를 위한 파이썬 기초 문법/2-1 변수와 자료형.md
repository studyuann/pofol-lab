# 2-1. 변수와 자료형

## 학습 목표

* 변수의 의미를 설명할 수 있다.

* 문자열, 정수, 실수, 불린 자료형을 구분할 수 있다.

* 변수에 값을 저장하고 출력할 수 있다.

* `type()` 함수를 사용해 자료형을 확인할 수 있다.

* 문자열과 숫자의 차이를 이해할 수 있다.

* f-string을 사용해 값을 보기 좋게 출력할 수 있다.

* 변수

* 자료형

* 문자열

* 실수

* type

---

## 1. 변수란 무엇인가

변수는 **값을 저장하는 이름**이다.

프로그램은 데이터를 처리하면서 값을 계속 사용하게 되는데, 이 값을 이름으로 저장해두면 다시 꺼내 쓰기 편하다.

예를 들어 다음 코드를 보자.

```
service_name = "EC2"
print(service_name)
```

이 코드에서

* `service_name`은 변수 이름

* `"EC2"`는 변수에 저장된 값

이다.

실행 결과는 다음과 같다.

```
EC2
```

즉, `"EC2"`라는 값을 `service_name`이라는 이름으로 저장했고, `print()`로 출력한 것이다.

---

## 2. 왜 변수를 사용하는가

변수를 사용하는 이유는 다음과 같다.

### 1) 값을 반복해서 사용할 수 있다

같은 값을 여러 번 직접 쓰는 대신 변수 이름만 사용하면 된다.

```
region = "ap-northeast-2"

print(region)
print(region)
print(region)
```

### 2) 값을 바꾸기 쉽다

값이 바뀌어야 할 때 한 곳만 수정하면 된다.

```
region = "ap-northeast-2"
print(region)

region = "us-east-1"
print(region)
```

### 3) 코드 의미를 더 분명하게 만들 수 있다

그냥 `"ap-northeast-2"`를 바로 쓰는 것보다 `region`이라는 이름으로 쓰면 의미가 더 잘 보인다.

---

## 3. 자료형이란 무엇인가

자료형은 **값의 종류**를 의미한다.

예를 들어 `"EC2"`는 글자이므로 문자열이고, `3`은 숫자이므로 정수이다.

Python은 값의 형태에 따라 자료형을 구분한다.

이 절에서는 자동화 코드에서 자주 보는 다음 4가지를 먼저 다룬다.

* 문자열(string)

* 정수(integer)

* 실수(float)

* 불린(boolean)

---

## 4. 문자열

문자열은 글자를 저장하는 자료형이다.

보통 따옴표로 감싸서 표현한다.

```
service_name = "EC2"
region = "ap-northeast-2"

print(service_name)
print(region)
```

실행 결과

```
EC2
ap-northeast-2
```

문자열은 다음처럼 한글도 가능하다.

```
message = "자동화 실습 시작"
print(message)
```

---

### 문자열 예제

```
instance_id = "i-1234567890abcdef0"
bucket_name = "my-log-bucket"
profile_name = "lab"

print(instance_id)
print(bucket_name)
print(profile_name)
```

이런 값들은 이후 AWS 자동화 코드에서 매우 자주 사용된다.

---

## 5. 정수

정수는 소수점이 없는 숫자이다.

```
instance_count = 3
port_number = 8080

print(instance_count)
print(port_number)
```

실행 결과

```
3
8080
```

정수는 수량, 개수, 포트 번호, 반복 횟수 같은 값을 표현할 때 자주 사용한다.

---

## 6. 실수

실수는 소수점이 있는 숫자이다.

```
cpu_usage = 73.5
memory_usage = 48.2

print(cpu_usage)
print(memory_usage)
```

실행 결과

```
73.5
48.2
```

실수는 CPU 사용률, 응답 시간, 평균값 같은 수치 데이터를 다룰 때 사용한다.

---

## 7. 불린

불린은 참과 거짓을 나타내는 자료형이다.

* `True`

* `False`

이 두 값만 가진다.

```
is_running = True
is_alarm = False

print(is_running)
print(is_alarm)
```

실행 결과

```
True
False
```

불린은 조건 판단에 매우 많이 사용된다.

예를 들어

* 실행 중인가

* 알람 상태인가

* 설정이 활성화되었는가

같은 상태를 표현할 때 사용한다.

---

## 8. 자료형 확인하기: type()

값이 어떤 자료형인지 확인하고 싶을 때 `type()` 함수를 사용한다.

```
service_name = "EC2"
instance_count = 3
cpu_usage = 73.5
is_running = True

print(type(service_name))
print(type(instance_count))
print(type(cpu_usage))
print(type(is_running))
```

실행 결과 예시

```
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
```

이 결과는 각각 다음 의미이다.

* `str` → 문자열

* `int` → 정수

* `float` → 실수

* `bool` → 불린

---

## 9. 문자열과 숫자의 차이

처음 Python을 배울 때 가장 자주 헷갈리는 부분 중 하나가 **문자열 숫자**와 **실제 숫자**의 차이이다.

예를 들어 아래 두 값은 겉보기에는 비슷하지만 완전히 다르다.

```
value1 = "100"
value2 = 100

print(type(value1))
print(type(value2))
```

실행 결과

```
<class 'str'>
<class 'int'>
```

* `"100"`은 문자열

* `100`은 정수

이다.

문자열 `"100"`은 글자 `"1"`, `"0"`, `"0"`이 이어진 값이고,

정수 `100`은 계산 가능한 숫자 값이다.

---

## 10. 문자열 연결

문자열끼리는 `+` 기호로 연결할 수 있다.

```
service = "EC2"
message = service + " 상태 확인"

print(message)
```

실행 결과

```
EC2 상태 확인
```

---

## 11. 문자열과 숫자를 바로 더할 수 없는 이유

문자열과 숫자는 자료형이 다르기 때문에 바로 `+`로 연결할 수 없다.

```
count = 3
# print("인스턴스 개수: " + count)
```

위 코드는 오류가 발생한다.

문자열과 숫자를 함께 출력하려면 숫자를 문자열로 바꾸어야 한다.

```
count = 3
print("인스턴스 개수: " + str(count))
```

실행 결과

```
인스턴스 개수: 3
```

여기서 `str(count)`는 숫자 `3`을 문자열 `"3"`으로 바꾸는 역할을 한다.

---

## 12. f-string

실무에서는 문자열 안에 변수를 넣어 출력할 때 **f-string**을 많이 사용한다.

가독성이 좋고 사용도 편하다.

형식은 다음과 같다.

```
name = "web-1"
state = "running"

print(f"name={name}, state={state}")
```

실행 결과

```
name=web-1, state=running
```

문자열 앞에 `f`를 붙이고, 변수는 중괄호 `{}` 안에 넣는다.

---

### f-string 예제 1

```
region = "ap-northeast-2"
profile = "lab"

print(f"region: {region}")
print(f"profile: {profile}")
```

### f-string 예제 2

```
instance_id = "i-1234567890abcdef0"
cpu_usage = 74.3

print(f"instance id: {instance_id}")
print(f"cpu usage: {cpu_usage}")
```

## 13. 자동화 코드에서 변수와 자료형이 어떻게 보이는가

이제 자동화 코드 스타일로 조금 더 비슷한 예제를 보자.

```
service_name = "EC2"
region = "ap-northeast-2"
instance_count = 4
cpu_usage = 81.7
is_alarm = True

print(f"service: {service_name}")
print(f"region: {region}")
print(f"instance count: {instance_count}")
print(f"cpu usage: {cpu_usage}")
print(f"alarm status: {is_alarm}")
```

이 코드는 실제 운영 자동화 코드에서 흔히 볼 수 있는 형태이다.

예를 들어

* 서비스 이름

* 리전 이름

* 인스턴스 개수

* 사용률 수치

* 경보 상태

같은 값을 변수로 저장하고 출력하는 식이다.

## 20. 자주 하는 실수

### 1) 문자열에 따옴표를 빼먹는 경우

```
# service_name = EC2
```

이렇게 쓰면 오류가 발생한다.

문자열은 반드시 따옴표로 감싸야 한다.

정상 예시

```
service_name = "EC2"
```

---

### 2) 문자열과 숫자를 바로 더하는 경우

```
count = 3
# print("count: " + count)
```

이 경우 오류가 발생한다.

정상 예시

```
count = 3
print("count: " + str(count))
```

또는

```
count = 3
print(f"count: {count}")
```

---

### 3) 불린을 문자열처럼 쓰는 경우

```
enabled = "True"
```

이건 문자열 `"True"`이지 불린 `True`가 아니다.

불린은 따옴표 없이 써야 한다.

```
enabled = True
```

---

## 21. 정리

* 변수는 값을 저장하는 이름이다.

* 문자열은 글자 데이터이다.

* 정수는 소수점 없는 숫자이다.

* 실수는 소수점 있는 숫자이다.

* 불린은 참과 거짓을 나타낸다.

* `type()`으로 자료형을 확인할 수 있다.

* 문자열과 숫자는 다르므로 함께 출력할 때 주의해야 한다.

* f-string은 자동화 코드 출력에 매우 유용하다.
