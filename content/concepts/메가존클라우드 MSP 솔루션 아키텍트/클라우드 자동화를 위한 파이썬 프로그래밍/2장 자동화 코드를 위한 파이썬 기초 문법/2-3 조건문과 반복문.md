# 2-3. 조건문과 반복문

## 학습 목표

* 조건문의 의미를 설명할 수 있다.

* `if`, `elif`, `else`를 사용해 조건에 따라 분기할 수 있다.

* 반복문의 의미를 설명할 수 있다.

* `for` 문을 사용해 리스트를 순회할 수 있다.

* 반복문과 조건문을 함께 사용해 원하는 데이터만 필터링할 수 있다.

* 자동화 코드에서 자주 나오는 상태값 분기와 목록 반복 처리 구조를 읽고 수정할 수 있다.

---

## 주요 키워드

* if

* elif

* else

* for

* 조건 분기

* 반복 처리

* 필터링

* 상태값

* 리스트 순회

---

## 1. 조건문이 필요한 이유

자동화 코드에서는 모든 데이터를 똑같이 처리하지 않는다.

예를 들어 다음과 같은 경우를 생각할 수 있다.

* `running` 상태인 인스턴스만 출력하고 싶다.

* CPU 사용률이 80 이상인 경우만 경고를 출력하고 싶다.

* 특정 리전인 경우만 처리하고 싶다.

* 파일이 있으면 읽고, 없으면 오류 메시지를 출력하고 싶다.

이런 경우에는 **조건에 따라 다르게 동작하는 코드**가 필요하다.

이때 사용하는 문법이 조건문이다.

---

# 2. if 문

## 2.1 if 문의 기본 구조

가장 기본적인 조건문은 `if`이다.

```
state = "running"

if state == "running":
    print("instance is running")
```

실행 결과

```
instance is running
```

여기서 중요한 부분은 다음과 같다.

* `if` 뒤에는 조건이 온다.

* 조건이 참이면 `:` 아래의 코드가 실행된다.

* 들여쓰기된 부분이 조건문에 속한다.

---

## 2.2 조건이 거짓이면 실행되지 않음

```
state = "stopped"

if state == "running":
    print("instance is running")
```

실행 결과는 아무 것도 없다.

왜냐하면 `state == "running"` 조건이 거짓이기 때문이다.

---

## 2.3 비교 연산자

조건문에서는 비교 연산자를 자주 사용한다.

### 같다

```
==
```

### 같지 않다

```
!=
```

### 크다

```
>
```

### 작다

```
<
```

### 크거나 같다

```
>=
```

### 작거나 같다

```
<=
```

예제

```
cpu_usage = 85

if cpu_usage > 80:
    print("high cpu usage")
```

실행 결과

```
high cpu usage
```

파일명: `if_basic.py`

* 조건이 참일 때만 실행된다는 점을 확인한다.

# 3. if - else

## 3.1 두 가지 경우로 나누기

조건이 참일 때와 거짓일 때를 나누고 싶다면 `else`를 사용한다.

```
state = "stopped"

if state == "running":
    print("instance is running")
else:
    print("instance is not running")
```

실행 결과

```
instance is not running
```

여기서는 두 경우 중 하나가 반드시 실행된다.

---

## 3.2 자동화 코드에서의 사용 예

```
is_alarm = True

if is_alarm:
    print("경고 상태")
else:
    print("정상 상태")
```

실행 결과

```
경고 상태
```

불린 값과 함께 사용하면 더 직관적이다.

---

## 실습 2. if - else 사용

파일명: `if_else_example.py`

```
cpu_usage = 73

if cpu_usage >= 80:
    print("CPU 사용률이 높음")
else:
    print("CPU 사용률이 정상 범위")
```

### 응용 실습

* `cpu_usage`를 `85`로 바꿔본다.

* `cpu_usage`를 `50`으로 바꿔본다.

* 어떤 조건에서 어떤 메시지가 나오는지 확인한다.

---

# 4. if - elif - else

## 4.1 여러 조건을 나눌 때 사용

두 가지 경우만 있는 것이 아니라 여러 상태를 나누고 싶을 때는 `elif`를 사용한다.

```
state = "stopped"

if state == "running":
    print("실행 중")
elif state == "stopped":
    print("중지 상태")
elif state == "terminated":
    print("종료 상태")
else:
    print("기타 상태")
```

실행 결과

```
중지 상태
```

---

## 4.2 상태값 분기 예시

이 구조는 EC2 상태, 서비스 상태, 로그 상태코드 분류 등에 매우 자주 사용된다.

```
status_code = 404

if status_code >= 500:
    print("서버 오류")
elif status_code >= 400:
    print("클라이언트 오류")
else:
    print("정상 또는 기타 응답")
```

실행 결과

```
클라이언트 오류
```

# 5. for 문

## 5.1 반복문이 필요한 이유

자동화 코드에서는 한 개만 처리하는 경우보다 여러 개를 반복해서 처리하는 경우가 더 많다.

예를 들면

* 여러 인스턴스 목록 출력

* 여러 버킷 이름 출력

* 로그 파일 여러 줄 읽기

* 여러 에러 패턴 집계

이런 경우에 반복문이 필요하다.

---

## 5.2 for 문의 기본 구조

```
services = ["EC2", "S3", "IAM"]

for service in services:
    print(service)
```

실행 결과

```
EC2
S3
IAM
```

이 구조를 해석하면 다음과 같다.

* `services`라는 리스트가 있다.

* 리스트 안의 값을 하나씩 꺼낸다.

* 꺼낸 값을 `service` 변수에 넣는다.

* 그 값을 출력한다.

---

## 5.3 반복문 안의 변수는 임시 변수

여기서 `service`는 반복문이 돌 때마다 값이 바뀌는 변수이다.

첫 번째 반복:

* `service = "EC2"`

두 번째 반복:

* `service = "S3"`

세 번째 반복:

* `service = "IAM"`

즉, 같은 변수 이름을 사용하지만 매 반복마다 다른 값이 들어간다.

---

## 실습 4. 리스트 반복 출력

파일명: `for_basic.py`

```
regions = ["ap-northeast-2", "us-east-1", "eu-west-1"]

for region in regions:
    print(region)
```

### 확인할 내용

* 리스트 안의 값이 순서대로 출력되는지 확인한다.

* 반복문이 리스트 길이만큼 실행되는지 확인한다.

# 7. 반복문과 조건문 함께 사용하기

이제 가장 중요한 구조를 본다.

자동화 코드에서는 `for`와 `if`를 함께 사용하는 경우가 매우 많다.

예를 들어 여러 인스턴스 중에서 `running` 상태만 출력하고 싶다고 해보자.

```
instances = [
    {"Name": "web-1", "State": "running"},
    {"Name": "db-1", "State": "stopped"},
    {"Name": "app-1", "State": "running"}
]

for instance in instances:
    if instance["State"] == "running":
        print(instance["Name"])
```

실행 결과

```
web-1
app-1
```

이 구조는 다음처럼 해석하면 된다.

1. 리스트 안의 인스턴스를 하나씩 꺼낸다.

2. 현재 인스턴스의 상태를 확인한다.

3. 상태가 `running`이면 이름을 출력한다.

즉, **반복 + 필터링** 구조이다.

---

## 실습 6. running 상태만 출력

파일명: `for_if_running.py`

```
instances = [
    {"Name": "web-1", "State": "running"},
    {"Name": "db-1", "State": "stopped"},
    {"Name": "app-1", "State": "running"},
    {"Name": "old-1", "State": "terminated"}
]

for instance in instances:
    if instance["State"] == "running":
        print(f"running instance: {instance['Name']}")
```

### 응용 실습

* `stopped` 상태만 출력하도록 바꿔본다.

* `terminated` 상태를 출력하도록 바꿔본다.

```
app-1 는 실행 중
old-1 는 기타 상태
```

# 9. 숫자 조건과 함께 사용하기

조건문은 문자열뿐 아니라 숫자에도 많이 사용한다.

예를 들어 CPU 사용률이 80 이상인 경우만 출력할 수 있다.

```
servers = [
    {"Name": "web-1", "Cpu": 35.2},
    {"Name": "db-1", "Cpu": 81.7},
    {"Name": "app-1", "Cpu": 64.4},
    {"Name": "batch-1", "Cpu": 92.1}
]

for server in servers:
    if server["Cpu"] >= 80:
        print(f"high cpu: {server['Name']} ({server['Cpu']})")
```

실행 결과

```
high cpu: db-1 (81.7)
high cpu: batch-1 (92.1)
```

# 10. 중첩 구조와 조건문

이제 조금 더 자동화 코드에 가까운 구조를 사용해보자.

```
instances = [
    {"Name": "web-1", "State": {"Name": "running"}},
    {"Name": "db-1", "State": {"Name": "stopped"}},
    {"Name": "app-1", "State": {"Name": "running"}}
]

for instance in instances:
    if instance["State"]["Name"] == "running":
        print(instance["Name"])
```

실행 결과

```
web-1
app-1
```

여기서는 `State`가 단순 문자열이 아니라 딕셔너리 안에 들어 있다.

그래서 `"State"]["Name"`까지 한 단계 더 들어가야 한다.

이 구조는 실제 boto3 응답과 매우 비슷하다.

# 12. 자주 하는 실수

## 12.1 들여쓰기를 하지 않는 경우

```
state = "running"

if state == "running":
print("running")
```

이 코드는 오류가 난다.

조건문 아래 코드는 반드시 들여쓰기해야 한다.

정상 예시

```
state = "running"

if state == "running":
    print("running")
```

---

## 12.2 `=`와 `==`를 혼동하는 경우

```
state = "running"

# if state = "running":
#     print("running")
```

조건 비교에서는 `=`이 아니라 `==`를 사용해야 한다.

정상 예시

```
if state == "running":
    print("running")
```

---

## 12.3 리스트 전체를 바로 비교하는 경우

```
states = ["running", "stopped", "running"]

# if states == "running":
#     print("found")
```

`states`는 리스트 전체이므로 문자열 하나와 직접 비교할 수 없다.

반복문으로 하나씩 꺼내야 한다.

정상 예시

```
for state in states:
    if state == "running":
        print("found")
```

## 12.4 중첩 구조에서 키를 하나 빼먹는 경우

```
instance = {
    "State": {
        "Name": "running"
    }
}

# if instance["State"] == "running":
#     print("running")
```

`instance["State"]`는 딕셔너리이다.

실제 값은 그 안의 `"Name"` 키에 들어 있다.

정상 예시

```
if instance["State"]["Name"] == "running":
    print("running")
```

# 13. 정리

* `if`는 조건이 참일 때만 실행된다.

* `else`는 조건이 거짓일 때 실행된다.

* `elif`는 여러 조건을 나누어 처리할 때 사용한다.

* `for`는 리스트 같은 여러 값을 하나씩 순서대로 처리할 때 사용한다.

* 반복문과 조건문을 함께 사용하면 원하는 항목만 필터링할 수 있다.

* 자동화 코드에서는 상태값 분기와 목록 반복 처리가 매우 자주 사용된다.

* 중첩된 딕셔너리 구조에서도 조건문을 사용할 수 있어야 한다.
