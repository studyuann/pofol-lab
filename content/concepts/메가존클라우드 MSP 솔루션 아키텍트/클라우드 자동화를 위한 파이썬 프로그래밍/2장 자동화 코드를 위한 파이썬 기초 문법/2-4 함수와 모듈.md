## 1. 함수가 필요한 이유

지금까지는 코드를 한 줄씩 위에서 아래로 작성했다.

이 방식은 간단한 예제에서는 괜찮지만, 자동화 코드가 길어지면 같은 작업이 반복되고 구조가 복잡해진다.

예를 들어 인스턴스 정보를 출력하는 코드가 여러 곳에 반복된다고 해보자.

```
instance1 = {"Name": "web-1", "State": "running"}
instance2 = {"Name": "db-1", "State": "stopped"}

print(f"name={instance1['Name']}, state={instance1['State']}")
print(f"name={instance2['Name']}, state={instance2['State']}")
```

이 코드는 지금은 짧지만, 인스턴스가 많아지면 같은 출력 코드가 계속 반복된다.

이럴 때 **반복되는 작업을 하나의 이름으로 묶는 기능**이 필요하다.

그 기능이 함수이다.

함수를 사용하면 다음과 같은 장점이 있다.

* 같은 코드를 여러 번 쓰지 않아도 된다.

* 코드 의미가 더 분명해진다.

* 수정할 때 한 곳만 바꾸면 된다.

* 자동화 코드 구조를 기능별로 나눌 수 있다.

---

## 2. 함수란 무엇인가

함수는 **특정 작업을 묶어 놓은 코드 블록**이다.

필요할 때 이름으로 호출해서 사용할 수 있다.

예를 들어 “인사 메시지 출력”이라는 작업을 함수로 만들 수 있다.

```
def hello():
    print("hello python")
```

여기서

* `def`는 함수를 정의할 때 사용하는 키워드

* `hello`는 함수 이름

* `()`는 함수 호출에 사용하는 기호

* `:` 아래 들여쓰기된 부분이 함수 본문

이다.

함수를 정의했다고 바로 실행되는 것은 아니다.

함수는 **호출**해야 실행된다.

```
def hello():
    print("hello python")

hello()
```

실행 결과

```
hello python
```

## 3. 함수 정의와 호출

함수는 보통 아래 형태로 작성한다.

```
def 함수이름():
    실행할 코드
```

그리고 함수 실행은 아래처럼 한다.

```
함수이름()
```

예제

```
def print_message():
    print("automation practice")

print_message()
```

실행 결과

```
automation practice
```

## 4. 매개변수와 인자

지금까지 본 함수는 항상 같은 내용만 출력했다.

하지만 자동화 코드에서는 상황에 따라 다른 값을 넣어야 하는 경우가 많다.

예를 들어 서비스 이름을 바꿔가며 출력하고 싶다고 해보자.

```
def print_service(service_name):
    print(f"service: {service_name}")

print_service("EC2")
print_service("S3")
print_service("IAM")
```

실행 결과

```
service: EC2
service: S3
service: IAM
```

여기서 중요한 개념이 있다.

* `service_name` → 함수 정의 쪽에 있는 값, **매개변수(parameter)**

* `"EC2"`, `"S3"`, `"IAM"` → 함수 호출 시 전달하는 값, **인자(argument)**

이라고 한다.

실습에서는 엄격히 구분하지 않고 함께 설명하는 경우도 많지만, 개념상으로는 이렇게 나뉜다.

---

## 5. 여러 개의 매개변수

함수는 값을 하나만 받는 것이 아니라 여러 개를 받을 수 있다.

```
def print_instance_info(name, state):
    print(f"name={name}, state={state}")

print_instance_info("web-1", "running")
print_instance_info("db-1", "stopped")
```

실행 결과

```
name=web-1, state=running
name=db-1, state=stopped
```

이 구조는 이후 EC2 상태 출력 코드에서 자주 사용된다.

---

## 6. 반환값과 return

함수는 단순히 출력만 하는 것이 아니라, 계산 결과나 문자열 결과를 **돌려줄 수 있다**.

이때 사용하는 키워드가 `return`이다.

```
def get_message(service_name):
    return f"{service_name} check completed"

message = get_message("EC2")
print(message)
```

실행 결과

```
EC2 check completed
```

여기서 함수는 문자열을 만들어 `return`으로 돌려준다.

그리고 그 결과를 `message` 변수에 저장한 것이다.

---

## 7. return이 필요한 이유

`print()`와 `return`은 역할이 다르다.

### `print()`

화면에 출력만 한다.

### `return`

함수 실행 결과를 밖으로 전달한다.

예를 들어 아래 함수는 화면에 출력만 한다.

```
def show_message():
    print("hello")
```

반면 아래 함수는 값을 돌려준다.

```
def make_message():
    return "hello"
```

자동화 코드에서는 값을 바로 출력할 때도 있지만,

다른 코드에서 계속 활용해야 할 때는 `return`이 더 중요하다.

---

## 8. return 예제

```
def get_instance_state():
    return "running"

state = get_instance_state()
print(state)
```

실행 결과

```
running
```

## 9. 자동화 코드에서 함수가 중요한 이유

자동화 코드에서는 보통 작업이 여러 단계로 나뉜다.

예를 들면 EC2 자동화에서는 다음과 같은 기능이 있을 수 있다.

* 인스턴스 목록 조회

* running 상태만 추출

* 출력 형식 정리

* CSV 저장

* 오류 처리

이 모든 코드를 한 파일에 한 줄로만 길게 작성하면 읽기 어렵고 수정도 불편하다.

그래서 작업을 함수로 나누는 것이 중요하다.

예를 들어 이렇게 나눌 수 있다.

```
def get_instances():
    ...

def filter_running_instances(instances):
    ...

def print_instances(instances):
    ...
```

이렇게 하면 코드를 읽을 때도 “어떤 기능인지” 이름으로 바로 알 수 있다.

## 10. 간단한 자동화 스타일 함수 예제

```
def print_instance_info(instance):
    print(
        f"name={instance['Name']}, "
        f"state={instance['State']}"
    )

instance = {"Name": "web-1", "State": "running"}
print_instance_info(instance)
```

실행 결과

```
name=web-1, state=running
```

이 구조는 매우 중요하다.

리스트 안 딕셔너리 구조에서 항목 하나를 꺼내 함수에 전달하면, 함수는 그 항목을 정리해서 출력할 수 있다.

---

## 11. 반복문과 함수 함께 사용하기

함수는 반복문과 함께 자주 사용된다.

```
def print_instance_info(instance):
    print(
        f"name={instance['Name']}, "
        f"state={instance['State']}"
    )

instances = [
    {"Name": "web-1", "State": "running"},
    {"Name": "db-1", "State": "stopped"},
    {"Name": "app-1", "State": "running"}
]

for instance in instances:
    print_instance_info(instance)
```

실행 결과

```
name=web-1, state=running
name=db-1, state=stopped
name=app-1, state=running
```

이 구조를 잘 보면 다음 흐름이다.

1. 리스트에서 인스턴스를 하나씩 꺼낸다.

2. 꺼낸 딕셔너리를 함수에 전달한다.

3. 함수는 전달받은 딕셔너리의 값을 출력한다.

즉, 반복 처리와 기능 분리가 함께 이루어진다.

## 실습 5. 자동화 스타일 함수 예제

```
def print_security_group_rule(rule):

        "Port": 443,
        "Source": "0.0.0.0/0",
        "Description": "HTTPS access from internet"

]

for rule in security_group_rules:
    print_security_group_rule(rule)
```

### 학습 포인트

이 예제는 이후 boto3 결과를 출력하는 패턴과 매우 비슷하다.

실제로는 `instances` 값이 고정 리스트가 아니라 AWS API 응답에서 온 값으로 바뀌게 된다.

## 12. 함수로 필터링 기능 만들기

단순 출력뿐 아니라 조건 필터링 기능도 함수로 만들 수 있다.

```
def print_security_rules_by_source(rules, source):
    for rule in rules:
        if rule["Source"] == source:
            print(f"{rule['Name']} - {rule['Port']}")

security_rules = [
    {
        "Name": "allow-ssh-internal",
        "Protocol": "tcp",
        "Port": 22,
        "Source": "10.0.0.0/24"
    },
    {
        "Name": "allow-http-public",
        "Protocol": "tcp",
        "Port": 80,
        "Source": "0.0.0.0/0"
    },
    {
        "Name": "allow-https-public",
        "Protocol": "tcp",
        "Port": 443,
        "Source": "0.0.0.0/0"
    }
]

print_security_rules_by_source(security_rules, "0.0.0.0/0")
```

실행 결과

```
allow-http-public - 80
allow-https-public - 443
```

이 함수는 “security group과 source를 입력받아서 “0.0.0.0/0”에 열려있는 규칙만 출력하는 기능”을 담당한다.

## 13. 함수 이름을 어떻게 지을까

함수 이름은 **무엇을 하는지 바로 드러나게** 짓는 것이 좋다.

예를 들어 아래처럼 짓는 것이 좋다.

* `print_instances`

* `get_running_instances`

* `save_report`

* `load_config`

* `read_log_file`

반대로 아래처럼 너무 모호한 이름은 좋지 않다.

* `do_work`

* `process`

* `test1`

* `abc`

자동화 코드에서는 기능이 많아지므로 함수 이름이 특히 중요하다.

## 14. 모듈이란 무엇인가

이제 `모듈(module)`을 보자.

모듈은 간단히 말해 **기능을 담고 있는 파일 또는 라이브러리**라고 생각하면 된다.

Python에서는 다른 기능을 가져와 쓸 때 `import`를 사용한다.

예를 들어 JSON을 다루기 위해 `json` 모듈을 가져올 수 있다.

```
import json
```

날짜와 시간을 쓰기 위해 `datetime` 모듈을 가져올 수도 있다.

```
from datetime import datetime
```

AWS 자동화에서는 가장 자주 보는 외부 라이브러리가 `boto3`이다.

```
import boto3
```

## 15. import의 의미

`import`는 다른 기능을 현재 코드 안으로 가져오는 것이다.

예를 들어 Python 기본 기능만으로는 JSON 파일 저장 기능이 바로 보이지 않는다.

하지만 `json` 모듈을 가져오면 JSON 관련 기능을 사용할 수 있다.

```
import json

data = {"service": "EC2", "region": "ap-northeast-2"}
text = json.dumps(data)

print(text)
```

실행 결과 예시

```
{"service": "EC2", "region": "ap-northeast-2"}
```

## 16. 모듈 전체 가져오기와 일부 가져오기

### 모듈 전체 가져오기

```
import json
```

이 경우 사용할 때 `json.dumps()`처럼 모듈 이름을 함께 적는다.

### 필요한 기능만 가져오기

```
from datetime import datetime
```

이 경우에는 바로 `datetime.now()`처럼 사용할 수 있다.

예제

```
from datetime import datetime

print(datetime.now())
```

## 17. 표준 모듈과 외부 라이브러리

Python에서 사용하는 모듈은 크게 두 종류가 있다.

### 표준 모듈

Python 설치 시 기본으로 제공되는 기능이다.

예:

* `json`

* `os`

* `datetime`

### 외부 라이브러리

별도로 설치해야 하는 기능이다.

예:

* `boto3`

* `requests`

외부 라이브러리는 보통 `pip install`로 설치한다.

예:

```
pip install boto3
```

## 19. 자동화 코드 스타일 종합 예제

이제 함수와 모듈을 함께 사용한 자동화 스타일 예제를 보자.

파일명: `function_module_summary.py`

```
import json

def print_instance_info(instance):
    print(
        f"id={instance['InstanceId']}, "
        f"name={instance.get('Name', 'NoName')}, "
        f"state={instance['State']}"
    )

def print_instances_as_json(instances):
    json_text = json.dumps(instances, ensure_ascii=False, indent=2)
    print(json_text)

instances = [
    {"InstanceId": "i-1111", "Name": "web-1", "State": "running"},
    {"InstanceId": "i-2222", "State": "stopped"},
    {"InstanceId": "i-3333", "Name": "app-1", "State": "running"}
]

for instance in instances:
    print_instance_info(instance)

print("\nJSON 형식으로 출력")
print_instances_as_json(instances)
```

### 학습 포인트

이 예제에는 지금까지 배운 여러 요소가 함께 들어 있다.

* 함수 정의

* 매개변수

* 반복문

* 딕셔너리 조회

* `get()` 사용

* `import json`

이 구조는 이후 실제 AWS 자동화 결과를 저장하는 코드와 매우 비슷하다.

## 20. 자주 하는 실수

### 20.1 함수 정의만 하고 호출하지 않는 경우

```
def hello():
    print("hello")
```

이렇게만 쓰면 아무 것도 실행되지 않는다.

함수는 반드시 호출해야 한다.

```
hello()
```

---

### 20.2 return과 print를 혼동하는 경우

```
def get_message():
    print("hello")
```

이 함수는 화면 출력만 하고 값을 돌려주지는 않는다.

함수 결과를 변수에 저장하려면 `return`이 필요하다.

```
def get_message():
    return "hello"
```

---

### 20.3 매개변수 개수를 맞추지 않는 경우

```
def print_info(name, state):
    print(name, state)

# print_info("web-1")
```

이 코드는 인자가 부족해서 오류가 난다.

정의한 매개변수 개수에 맞게 호출해야 한다.

---

### 20.4 import 없이 모듈 기능을 사용하는 경우

```
# print(json.dumps({"a": 1}))
```

이렇게 쓰면 `json`이 무엇인지 알 수 없기 때문에 오류가 난다.

먼저 `import json`이 필요하다.

---

## 21. 정리

* 함수는 특정 작업을 묶어 놓은 코드 블록이다.

* `def`로 함수를 정의하고, 이름 뒤에 `()`를 붙여 호출한다.

* 매개변수를 사용하면 함수에 값을 전달할 수 있다.

* `return`을 사용하면 함수 결과를 밖으로 전달할 수 있다.

* 자동화 코드에서는 조회, 출력, 저장 같은 기능을 함수로 나누는 것이 중요하다.

* `import`는 다른 기능을 현재 코드로 가져오는 문법이다.

* `json` 같은 표준 모듈과 `boto3` 같은 외부 라이브러리를 구분할 수 있어야 한다.
