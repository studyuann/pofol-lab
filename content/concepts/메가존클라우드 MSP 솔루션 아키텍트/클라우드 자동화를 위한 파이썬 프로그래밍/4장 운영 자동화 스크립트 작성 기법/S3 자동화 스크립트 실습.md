# S3 자동화 스크립트 실습

## 개요

이 장에서는 `boto3`를 사용해 S3 버킷과 객체를 조회하고, 로컬 파일을 S3로 업로드하거나 S3 객체를 로컬로 다운로드하는 자동화 코드를 작성한다.

또한 `prefix`를 활용한 객체 필터링, 예외 처리, 함수 분리를 통한 코드 구조 개선까지 함께 다룬다.

이 장의 목표는 S3를 콘솔에서 사용하는 수준을 넘어서, **파일 처리 작업을 Python 코드로 자동화하는 흐름**을 익히는 것이다.

이 장을 마치면 다음을 할 수 있어야 한다.

* `download_file()`을 사용해 S3 객체를 로컬 파일로 다운로드할 수 있다.

* 함수 분리와 예외 처리를 통해 S3 자동화 코드를 정리할 수 있다.

# 6.1 S3 자동화 개요

## 1. S3란 무엇인가

S3는 AWS의 객체 스토리지 서비스이다.

파일을 S3에 저장할 때는 보통 다음 개념을 함께 보게 된다.

* **Bucket**: 객체를 저장하는 상위 저장소

* **Object**: 실제 저장되는 데이터

* **Key**: 객체의 이름 또는 경로처럼 보이는 식별자

예를 들어 `reports/2026/report.txt` 같은 문자열은 S3에서 디렉터리 자체라기보다 **객체 Key**로 취급된다.

---

## 2. 왜 S3 자동화가 중요한가

S3는 다음과 같은 작업에서 자주 사용된다.

* 로그 파일 업로드

* 결과 보고서 저장

* 백업 파일 보관

* 분석 대상 파일 다운로드

* 자동화 결과 공유

이런 작업을 콘솔에서 수동으로 할 수도 있지만, Python 코드로 자동화하면 반복 작업을 훨씬 효율적으로 처리할 수 있다.

---

# 6.2 S3 버킷 목록 조회

## 1. 기본 조회 API

S3 버킷 목록을 조회할 때는 `list_buckets()`를 사용한다.

이 API는 **현재 인증된 요청자가 소유한 버킷 목록**을 반환한다. 또한 이 작업에는 `s3:ListAllMyBuckets` 권한이 필요하다.

기본 구조는 다음과 같다.

```
import boto3

session = boto3.Session(profile_name="lab")
s3 = session.client("s3", region_name="ap-northeast-2")

response = s3.list_buckets()
print(response)
```

---

## 2. 응답 구조 이해

`list_buckets()` 응답에는 보통 `Buckets` 리스트가 포함된다.

각 버킷 항목에는 버킷 이름과 생성일 같은 정보가 들어 있다.

즉, 구조는 대략 다음과 같다.

```
{
    "Buckets": [
        {"Name": "bucket-1", "CreationDate": "..."},
        {"Name": "bucket-2", "CreationDate": "..."}
    ],
    "Owner": {...}
}
```

따라서 버킷 이름만 출력하려면 `response["Buckets"]`를 반복하면 된다.

---

## 3. 버킷 이름 출력

```
import boto3

session = boto3.Session(profile_name="lab")
s3 = session.client("s3", region_name="ap-northeast-2")

response = s3.list_buckets()

for bucket in response["Buckets"]:
    print(bucket["Name"])
```

* 리스트 안 각 항목이 딕셔너리라는 점을 확인한다.

# 6.3 S3 객체 목록 조회

## 1. 객체 조회 API

버킷 안의 객체를 조회할 때는 `list_objects_v2()`를 많이 사용한다.

이 API는 지정한 버킷 안의 객체 목록을 반환한다.

기본 구조는 다음과 같다.

```
import boto3

session = boto3.Session(profile_name="lab")
s3 = session.client("s3", region_name="ap-northeast-2")

response = s3.list_objects_v2(Bucket="my-log-bucket")
print(response)
```

---

## 2. 응답 구조 이해

객체 목록은 보통 `Contents` 리스트 안에 들어 있다.

각 객체 항목에는 `Key`, `Size`, `LastModified` 같은 정보가 들어간다.

즉, 구조는 대략 다음과 같다.

```
{
    "Contents": [
        {"Key": "report.txt", "Size": 123},
        {"Key": "logs/app.log", "Size": 456}
    ]
}
```

따라서 객체 이름을 출력하려면 `response["Contents"]`를 반복하며 `Key`를 꺼내면 된다.

단, 버킷이 비어 있으면 `Contents` 키가 없을 수도 있으므로 `get()`을 사용하는 것이 더 안전하다.

---

## 3. 객체 Key 출력

```
import boto3

session = boto3.Session(profile_name="lab")
s3 = session.client("s3", region_name="ap-northeast-2")

response = s3.list_objects_v2(Bucket="my-log-bucket")

for obj in response.get("Contents", []):
    print(obj["Key"])
```

---

## 실습 2. 객체 목록 조회

파일명: `s3_list_objects.py`

```
import boto3

session = boto3.Session(profile_name="lab")
s3 = session.client("s3", region_name="ap-northeast-2")

bucket_name = "my-log-bucket"
response = s3.list_objects_v2(Bucket=bucket_name)

print(f"bucket: {bucket_name}")
for obj in response.get("Contents", []):
    print(obj["Key"])
```

* 버킷 이름을 변수로 분리한다.

* `Contents`가 없을 수 있으므로 `get("Contents", [])`를 사용한다.

* 객체 Key가 실제 파일 경로처럼 보이지만 S3에서는 객체 이름이라는 점을 이해한다.

# 6.4 prefix 기반 객체 조회

## 1. prefix란 무엇인가

S3에는 전통적인 디렉터리가 없지만, Key 문자열 앞부분을 활용해 경로처럼 관리하는 경우가 많다.

예를 들어 아래 Key들이 있다고 하자.

* `logs/app.log`

* `logs/error.log`

* `reports/daily.txt`

이때 `logs/`를 기준으로 조회하면 로그 관련 객체만 찾을 수 있다.

---

## 2. Prefix 옵션 사용

`list_objects_v2()`에는 `Prefix` 옵션을 줄 수 있다.

```
import boto3

session = boto3.Session(profile_name="lab")
s3 = session.client("s3", region_name="ap-northeast-2")

response = s3.list_objects_v2(
    Bucket="my-log-bucket",
    Prefix="logs/"
)

for obj in response.get("Contents", []):
    print(obj["Key"])
```

이 코드는 `logs/`로 시작하는 Key만 조회한다.

---

## 실습 3. prefix 기반 조회

파일명: `s3_prefix_list.py`

```
import boto3

session = boto3.Session(profile_name="lab")
s3 = session.client("s3", region_name="ap-northeast-2")

bucket_name = "my-log-bucket"
prefix = "logs/"

response = s3.list_objects_v2(Bucket=bucket_name, Prefix=prefix)

print(f"bucket: {bucket_name}")
print(f"prefix: {prefix}")

for obj in response.get("Contents", []):
    print(obj["Key"])
```

* `Prefix`를 사용하면 특정 경로처럼 보이는 그룹만 볼 수 있다.

* S3 객체 Key 설계가 자동화 편의성과 연결된다는 점을 이해한다.

# 6.5 로컬 파일 업로드 자동화

## 1. upload\_file() 메서드

로컬 파일을 S3에 올릴 때는 `upload_file()`을 많이 사용한다.

`upload_file(Filename, Bucket, Key)` 형태로 사용하며, `Filename`은 로컬 경로, `Bucket`은 버킷 이름, `Key`는 업로드할 객체 이름이다.

기본 예제는 다음과 같다.

```
import boto3

session = boto3.Session(profile_name="lab")
s3 = session.client("s3", region_name="ap-northeast-2")

s3.upload_file("report.txt", "my-log-bucket", "reports/report.txt")
```

이 코드는 로컬의 `report.txt` 파일을 S3 버킷 `my-log-bucket`의 `reports/report.txt`라는 Key로 업로드한다.

파일 업로드/다운로드 같은 전송 작업에서 SDK가 재시도와 멀티파트/비멀티파트 전송을 기본 설정으로 관리한다.

---

## 2. 업로드 성공 메시지 추가

```
import boto3

session = boto3.Session(profile_name="lab")
s3 = session.client("s3", region_name="ap-northeast-2")

local_file = "report.txt"
bucket_name = "my-log-bucket"
object_key = "reports/report.txt"

s3.upload_file(local_file, bucket_name, object_key)

print("업로드 완료")
print(f"local file: {local_file}")
print(f"bucket: {bucket_name}")
print(f"key: {object_key}")
```

# 6.6 S3 객체 다운로드 자동화

## 1. download\_file() 메서드

S3 객체를 로컬 파일로 저장할 때는 `download_file()`을 사용한다.

boto3 문서에는 S3 client, Bucket, Object에 다운로드 변형 메서드가 주입되어 있으며, `download_file(bucket, key, filename)` 구조를 사용할 수 있다고 설명한다. ([AWS 문서](https://docs.aws.amazon.com/boto3/latest/reference/customizations/s3?utm_source=chatgpt.com))

기본 예제는 다음과 같다.

```
import boto3

session = boto3.Session(profile_name="lab")
s3 = session.client("s3", region_name="ap-northeast-2")

s3.download_file("my-log-bucket", "uploads/report.txt", "downloaded_report.txt")
```

이 코드는 S3 객체를 로컬의 `downloaded_report.txt`로 저장한다.

---

# 6.8 예외 처리 추가하기

S3 자동화에서도 예외 처리가 중요하다.

버킷 이름이 잘못되었거나, 파일이 없거나, 권한이 부족하면 오류가 발생할 수 있다.

---

## 1. 버킷 조회 예외 처리

```
import boto3

def get_s3_client():
    session = boto3.Session(profile_name="lab")
    return session.client("s3", region_name="ap-northeast-2")

def list_buckets():
    s3 = get_s3_client()
    response = s3.list_buckets()

    for bucket in response["Buckets"]:
        print(bucket["Name"])

try:
    list_buckets()
except Exception as e:
    print("버킷 목록 조회 실패")
    print(f"오류 내용: {e}")
```

---

## 2. 업로드 예외 처리

```
import boto3

def get_s3_client():
    session = boto3.Session(profile_name="lab")
```

# 6.10 자동화 스타일 종합 예제

이제 이 장의 흐름을 모은 종합 예제를 보자.

파일명: `s3_summary.py`

```
import boto3

def get_s3_client():
    session = boto3.Session(profile_name="lab")
    return session.client("s3", region_name="ap-northeast-2")

def list_buckets():
    s3 = get_s3_client()
    response = s3.list_buckets()

    print("버킷 목록")
    for bucket in response["Buckets"]:
        print(bucket["Name"])

def list_objects(bucket_name, prefix=None):
    s3 = get_s3_client()

    if prefix:
        response = s3.list_objects_v2(Bucket=bucket_name, Prefix=prefix)
    else:
        response = s3.list_objects_v2(Bucket=bucket_name)

    print(f"bucket: {bucket_name}")
    if prefix:
        print(f"prefix: {prefix}")

    for obj in response.get("Contents", []):
        print(obj["Key"])

def upload_file_to_s3(local_file, bucket_name, object_key):
    s3 = get_s3_client()
    s3.upload_file(local_file, bucket_name, object_key)

    print("업로드 완료")
    print(f"local file: {local_file}")
    print(f"bucket: {bucket_name}")
    print(f"key: {object_key}")

try:
    list_buckets()
    list_objects("my-log-bucket", "logs/")
    upload_file_to_s3("report.txt", "my-log-bucket", "uploads/report.txt")

except Exception as e:
    print("S3 자동화 실행 실패")
    print(f"오류 내용: {e}")
```

이 예제에는 다음 흐름이 들어 있다.

* 프로필 기반 S3 client 생성

* 버킷 목록 조회

* prefix 기반 객체 목록 조회

* 파일 업로드

* 함수 분리

* 예외 처리

즉, 이후 로그 분석 결과를 S3에 올리거나, 참고할 파일을 S3에서 내려받는 구조의 기본형으로도 확장할 수 있다.

# 6.11 자주 하는 실수

## 1. Bucket과 Key를 혼동하는 경우

예를 들어 아래는 서로 다른 개념이다.

* Bucket: `my-log-bucket`

* Key: `uploads/report.txt`

버킷은 저장소 이름이고, Key는 그 안의 객체 이름이다.

---

## 2. 업로드와 다운로드 인자 순서를 혼동하는 경우

`upload_file()`과 `download_file()`은 모두 세 개의 주요 인자를 쓰지만 의미를 구분해야 한다.

업로드는 로컬 파일을 S3로 보내고, 다운로드는 S3에서 로컬로 가져온다.

---

## 3. 버킷이 비어 있을 때 `Contents` 키가 없을 수 있다는 점을 놓치는 경우

```
response["Contents"]
```

이렇게 바로 접근하면 오류가 날 수 있다.

가능하면 아래처럼 쓴다.

```
response.get("Contents", [])
```

---

## 4. 로컬 파일 경로를 잘못 적는 경우

업로드 시 가장 흔한 실수 중 하나는 로컬 파일명이 잘못된 경우이다.

실행 디렉터리와 파일 위치를 함께 확인해야 한다.

---

## 5. 조회 코드와 업로드/다운로드 코드를 섞어 복잡하게 만드는 경우

처음에는 기능별로 함수를 분리하는 것이 좋다.

* 버킷 목록 조회 함수

* 객체 목록 조회 함수

* 업로드 함수

* 다운로드 함수

이렇게 나누면 유지보수가 쉬워진다.

# 6.12 정리

* `list_buckets()`로 현재 인증된 요청자가 소유한 버킷 목록을 조회할 수 있다.

* `list_objects_v2()`로 버킷 안 객체 목록을 조회할 수 있다.

* 객체 목록은 보통 `Contents` 리스트에 들어 있으므로 `get("Contents", [])`를 사용하는 것이 안전하다.

* `Prefix`를 사용하면 특정 경로처럼 보이는 Key 그룹만 조회할 수 있다.

* `upload_file()`로 로컬 파일을 S3 객체로 업로드할 수 있고, `download_file()`로 S3 객체를 로컬 파일로 저장할 수 있다.

* boto3는 파일 전송 시 재시도와 멀티파트/비멀티파트 전송을 기본 설정으로 관리한다.

* 함수 분리와 예외 처리를 통해 S3 자동화 코드를 더 읽기 좋고 안정적으로 만들 수 있다.

* 생성형 AI에게 S3 코드 생성을 요청할 때는 프로필, 리전, 버킷 이름, Key, 성공 메시지, 예외 처리 조건을 함께 적는 것이 좋다.
