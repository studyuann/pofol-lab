# 자연어 기반 S3 데이터 분석 환경 구성

## Amazon S3 + Athena + 샘플 데이터 준비

---

# 1. 실습 개요

이번 실습에서는 S3에 저장된 CSV 데이터를 대상으로 자연어 기반 데이터 분석 파이프라인을 구성한다.

최종적으로 만들 파이프라인은 다음과 같다.

```
사용자 자연어 질문
        ↓
Streamlit 웹 화면
        ↓
Amazon Bedrock
자연어 질문을 SQL로 변환
        ↓
Amazon Athena
S3 데이터 조회
        ↓
Amazon S3
CSV 원천 데이터 및 Athena 결과 저장
        ↓
Python pandas
결과 데이터 처리
        ↓
Streamlit + Plotly
표와 차트 출력
```

이 중 자연어 분석 앱을 만들기 전에 필요한 데이터 분석 환경을 먼저 준비한다.

실습 범위는 다음과 같다.

```
프로젝트 디렉터리 생성
        ↓
Python 가상환경 구성
        ↓
환경 변수 파일 작성
        ↓
S3 버킷 생성
        ↓
샘플 CSV 데이터 생성
        ↓
CSV 데이터 S3 업로드
        ↓
Athena 결과 저장 경로 준비
        ↓
Athena 데이터베이스 생성
        ↓
Athena 외부 테이블 생성
        ↓
Athena SQL 조회 테스트
```

다음 실습에서 Amazon Bedrock을 사용해 자연어 질문을 SQL로 변환하고, Streamlit으로 결과를 시각화한다.

# 6. 환경 변수 파일 작성

## 6.1 환경 변수 파일을 사용하는 이유

실습 코드에는 다음과 같은 값이 필요하다.

```
AWS 리전
S3 버킷 이름
S3 데이터 저장 경로
Athena 결과 저장 경로
Athena 데이터베이스 이름
Athena 테이블 이름
```

이 값을 Python 코드 안에 직접 작성할 수도 있다.

하지만 코드 안에 직접 작성하면 다음 문제가 생긴다.

```
학생마다 버킷 이름이 달라서 코드 수정이 많아진다
환경이 바뀔 때마다 코드 전체를 수정해야 한다
민감한 설정값이 코드에 섞인다
코드 재사용성이 떨어진다
```

따라서 이번 실습에서는 `.env` 파일에 환경별 설정값을 분리한다.

---

# 7. S3 버킷 생성

## 7.1 S3 버킷 이름 확인

먼저 `.env` 파일에 작성한 버킷 이름을 확인한다.

```
S3_BUCKET=nlp-s3-analytics-kim-123456789012
```

이 값과 동일한 이름으로 S3 버킷을 생성한다.

---

## 7.2 버킷 생성

아래 명령어에서 버킷 이름은 본인의 값으로 변경한다.

```
aws s3api create-bucket \
--bucket nlp-s3-analytics-kim-123456789012 \
--region ap-northeast-2 \
--create-bucket-configurationLocationConstraint=ap-northeast-2
```

명령어 설명은 다음과 같다.

| 옵션 | 설명 |
| --- | --- |
| `aws s3api create-bucket` | S3 버킷을 생성한다 |
| `--bucket` | 생성할 버킷 이름을 지정한다 |
| `--region` | 버킷을 생성할 리전을 지정한다 |
| `--create-bucket-configuration` | 버킷 생성 위치 설정을 지정한다 |
| `LocationConstraint=ap-northeast-2` | 버킷을 서울 리전에 생성한다 |

서울 리전처럼 `us-east-1`이 아닌 리전에 버킷을 만들 때는 `--create-bucket-configuration LocationConstraint=ap-northeast-2` 옵션이 필요하다.

특정 버킷만 확인한다.

aws s3 ls s3://nlp-s3-analytics-kim-123456789012

# 8. 샘플 데이터 생성

## 8.1 샘플 데이터 개요

이번 실습에서는 가상의 전자상거래 주문 데이터를 사용한다.

파일명은 다음과 같다.

```
ecommerce_sales.csv
```

데이터는 2026년 1월 1일부터 90일 동안의 주문 내역을 가정한다.

주문 데이터에는 다음 정보가 포함된다.

```
주문 ID
주문일
고객 ID
지역
상품 카테고리
상품명
판매 채널
주문 수량
상품 단가
할인 금액
결제 방식
반품 여부
```

---

## 8.2 데이터 컬럼 설명

| 컬럼명 | 타입 | 설명 |
| --- | --- | --- |
| `order_id` | string | 주문 ID |
| `order_date` | date | 주문일 |
| `customer_id` | string | 고객 ID |
| `region` | string | 주문 지역 |
| `category` | string | 상품 카테고리 |
| `product_name` | string | 상품명 |
| `channel` | string | 판매 채널 |
| `quantity` | int | 주문 수량 |
| `unit_price` | int | 상품 단가 |
| `discount_amount` | int | 할인 금액 |
| `payment_method` | string | 결제 방식 |
| `is_returned` | boolean | 반품 여부 |

매출은 다음 공식으로 계산한다.

```
매출 = quantity * unit_price - discount_amount
```

예를 들어 다음 주문이 있다고 가정한다.

| quantity | unit\_price | discount\_amount |
| --- | --- | --- |
| 3 | 25000 | 5000 |

매출은 다음과 같이 계산한다.

```
3 * 25000 - 5000 = 70000
```

---

## 8.3 샘플 데이터 생성 코드

파일명: `01_generate_sample_data.py`

```
import csv
import random
from datetime import date, timedelta
from pathlib import Path

OUTPUT_DIR = Path("data")
OUTPUT_DIR.mkdir(exist_ok=True)

OUTPUT_FILE = OUTPUT_DIR / "ecommerce_sales.csv"

categories = ["전자기기", "도서", "패션", "생활용품", "식품", "스포츠"]
regions = ["서울", "경기", "부산", "대구", "광주", "대전", "인천"]
channels = ["web", "mobile", "store"]
payment_methods = ["card", "bank_transfer", "point", "coupon"]

start_date = date(2026, 1, 1)
days = 90

random.seed(42)

with OUTPUT_FILE.open("w", newline="", encoding="utf-8-sig") as f:
    writer = csv.writer(f)
    writer.writerow([
        "order_id",
        "order_date",
        "customer_id",
        "region",
        "category",
        "product_name",
        "channel",
        "quantity",
        "unit_price",
        "discount_amount",
        "payment_method",
        "is_returned"
    ])

    order_no = 1

    for day_offset in range(days):
        current_date = start_date + timedelta(days=day_offset)
        daily_orders = random.randint(20, 45)

        for _ in range(daily_orders):
            category = random.choice(categories)

            if category == "전자기기":
                product = random.choice(["무선이어폰", "키보드", "마우스", "모니터", "USB허브"])
                price = random.choice([25000, 45000, 79000, 150000, 320000])
            elif category == "도서":
                product = random.choice(["클라우드입문", "파이썬기초", "보안개론", "네트워크실습"])
                price = random.choice([15000, 22000, 28000, 35000])
            elif category == "패션":
                product = random.choice(["티셔츠", "운동화", "자켓", "가방"])
                price = random.choice([19000, 49000, 89000, 129000])
            elif category == "생활용품":
                product = random.choice(["수납박스", "텀블러", "책상조명", "청소도구"])
                price = random.choice([9000, 15000, 23000, 37000])
            elif category == "식품":
                product = random.choice(["커피", "간편식", "견과류", "비타민음료"])
                price = random.choice([6000, 11000, 18000, 26000])
            else:
                product = random.choice(["요가매트", "덤벨", "운동밴드", "러닝벨트"])
                price = random.choice([12000, 24000, 39000, 59000])

            quantity = random.randint(1, 5)
            discount = random.choice([0, 0, 0, 1000, 2000, 5000])
            is_returned = random.choice([False, False, False, False, True])

            writer.writerow([
                f"ORD-{order_no:06d}",
                current_date.isoformat(),
                f"CUST-{random.randint(1, 500):04d}",
                random.choice(regions),
                category,
                product,
                random.choice(channels),
                quantity,
                price,
                discount,
                random.choice(payment_methods),
                str(is_returned).lower()
            ])

            order_no += 1

print(f"샘플 데이터 생성 완료: {OUTPUT_FILE}")
```

# 9. CSV 데이터를 S3에 업로드

## 9.1 업로드 코드 작성

파일명: `02_upload_to_s3.py`

```
import os
from pathlib import Path
from dotenv import load_dotenv
import boto3

load_dotenv()

AWS_REGION = os.getenv("AWS_REGION", "ap-northeast-2")
S3_BUCKET = os.getenv("S3_BUCKET")
DATA_PREFIX = os.getenv("DATA_PREFIX", "datasets/ecommerce_sales/")

LOCAL_FILE = Path("data/ecommerce_sales.csv")

if not S3_BUCKET:
    raise ValueError(".env 파일에 S3_BUCKET 값을 설정해야 한다.")

if not LOCAL_FILE.exists():
    raise FileNotFoundError("data/ecommerce_sales.csv 파일이 없다. 먼저 01_generate_sample_data.py를 실행한다.")

s3 = boto3.client("s3", region_name=AWS_REGION)

key = f"{DATA_PREFIX.rstrip('/')}/ecommerce_sales.csv"
s3.upload_file(str(LOCAL_FILE), S3_BUCKET, key)

print("S3 업로드 완료")
print(f"s3://{S3_BUCKET}/{key}")
```

DROP TABLE IF EXISTS nlp_s3_analytics_db.ecommerce_sales;

)
ROW FORMAT SERDE 'org.apache.hadoop.hive.serde2.OpenCSVSerde'
WITH SERDEPROPERTIES (
    'separatorChar' = ',',
    'quoteChar' = '"',
    'escapeChar' = '\\'
)
STORED AS TEXTFILE
LOCATION 's3://nlp-s3-analytics-kim-123456789012/datasets/ecommerce_sales/'
TBLPROPERTIES (
    'skip.header.line.count' = '1'
);
```

```

```

CSV 파일을 해석하기 위한 SerDe를 지정한다.

'quoteChar'='"',
'escapeChar'='\\'

| 속성 | 설명 |
| --- | --- |
| `separatorChar` | 컬럼 구분자이다. CSV에서는 쉼표 `,`를 사용한다 |
| `quoteChar` | 문자열 값을 감싸는 따옴표 문자이다 |
| `escapeChar` | 특수 문자를 이스케이프할 때 사용하는 문자이다 |

---

```
STOREDAS TEXTFILE
```

FROM nlp_s3_analytics_db.ecommerce_sales;

SQL 설명은 다음과 같다.

| 구문 | 설명 |
| --- | --- |
| `COUNT(*)` | 전체 행 수를 센다 |
| `AS order_count` | 결과 컬럼 이름을 `order_count`로 표시한다 |

order_count

2940

## 12.4 카테고리별 매출 조회

```
SELECT
  category,
  SUM(quantity* unit_price- discount_amount) AS sales
FROM nlp_s3_analytics_db.ecommerce_sales
GROUP BY category
ORDER BY salesDESC;
```

SQL 설명은 다음과 같다.

| 구문 | 설명 |
| --- | --- |
| `category` | 상품 카테고리를 조회한다 |
| `SUM(quantity * unit_price - discount_amount)` | 카테고리별 매출을 계산한다 |
| `GROUP BY category` | 카테고리별로 데이터를 묶는다 |
| `ORDER BY sales DESC` | 매출이 높은 순서로 정렬한다 |

예상 결과 형태는 다음과 같다.

```
category    sales

생활용품      2345670
스포츠        1987650
식품          1567890

## 12.5 월별 매출 조회

```
SELECT
  date_format(order_date,'%Y-%m') AS order_month,
  SUM(quantity* unit_price- discount_amount) AS sales
FROM nlp_s3_analytics_db.ecommerce_sales
GROUP BY date_format(order_date,'%Y-%m')
ORDER BY order_month;
```

SQL 설명은 다음과 같다.

| 구문 | 설명 |
| --- | --- |
| `date_format(order_date, '%Y-%m')` | 주문일을 `연-월` 형식으로 변환한다 |
| `SUM(...)` | 월별 매출을 합산한다 |
| `GROUP BY date_format(...)` | 월별로 데이터를 묶는다 |
| `ORDER BY order_month` | 월 순서대로 정렬한다 |

예상 결과 형태는 다음과 같다.

```
order_month    sales
-------------  ----------
2026-01        12345678
2026-02        11223344
2026-03        9988776
```
