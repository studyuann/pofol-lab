# Inbox

> 아직 처리되지 않은 메모들이 여기 쌓입니다.
> AI 큐레이터가 `concepts/`로 이동시켜 정리합니다.

## 사용법

1. 이 폴더에 `.md` 파일 생성
2. 생각나는 대로 적기 (완성도 무관)
3. AI에게 "inbox 처리해줘" 요청
4. AI가 자동으로 분류 · 정제 · 연결

## 예시 노트 형식

```markdown
# 아이디어 제목

내용을 자유롭게 적기...
- 키워드: #AI #생산성
```
