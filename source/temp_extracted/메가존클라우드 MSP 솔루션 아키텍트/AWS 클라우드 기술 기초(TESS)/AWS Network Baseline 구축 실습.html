AWS Network Baseline 구축 실습

AWS에서 기본 네트워크 환경을 구축한다.

VPC
 → Subnet
 → Routing Table
 → Internet Gateway
 → NAT Gateway

이 구조는 AWS에서 가장 기본적인 3-Tier 아키텍처 네트워크 구조의 기반이 되는 구성이다.

실습 규칙 (이니셜 Prefix 사용)

이번 실습에서는 모든 AWS 리소스 이름 앞에 자신의 이름 이니셜 Prefix를 붙여 생성한다.

이유

  • 여러 학생이 동일한 계정을 사용
  • 리소스 이름 충돌 방지
  • 관리 편의성

NAT Gateway 생성

NAT Gateway는 Private Subnet에서 Internet으로 나가는 트래픽을 허용하는 장비이다.

Private 인스턴스는 Internet에서 직접 접근할 수 없지만

NAT Gateway를 통해 Outbound 인터넷 연결이 가능하다.

생성해서 사용 후 삭제함. - 비용 발생
