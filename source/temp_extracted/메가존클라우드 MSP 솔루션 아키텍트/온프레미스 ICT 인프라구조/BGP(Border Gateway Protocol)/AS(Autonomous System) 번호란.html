AS(Autonomous System) 번호란?

AS(자율 시스템, Autonomous System) 번호는 인터넷 상에서 개별 네트워크를 식별하기 위해 사용되는 고유한 숫자이다. 인터넷은 여러 개의 독립적인 네트워크(AS)로 이루어져 있으며, 각 AS는 자체적인 라우팅 정책을 가지고 운영된다.

AS 번호의 역할

  • 인터넷에서 라우팅 경로를 결정하는 데 사용됨
  • BGP(Border Gateway Protocol) 를 통해 AS 간에 라우팅 정보를 교환
  • ISP, 대기업, 클라우드 서비스, 정부 기관 등에서 사용됨

16비트 AS 번호에서 32비트 AS 번호로 확장된 이유

초기에는 AS 번호가 16비트(2바이트) 로 설계되어 최대 65,536개(0~65535) 까지 할당할 수 있었다.

하지만 인터넷이 급격히 성장하면서 공인 AS 번호의 부족 문제가 발생했다.

이를 해결하기 위해 IANA(Internet Assigned Numbers Authority) 는

2007년부터 32비트(4바이트) AS 번호 체계를 도입하여 최대 42억 개(0~4,294,967,295) 까지 확장하였다.

16비트 → 32비트 AS 번호 전환 배경

  1. 인터넷 확장으로 인해 AS 번호 부족
    • ISP, 클라우드, 기업 네트워크 증가로 공인 AS 번호 소진
  1. IPv6 도입과 함께 확장 필요
    • IPv6 확산과 함께 인터넷 라우팅 시스템도 확장 필요
  1. 미래 확장성 확보
    • 32비트 AS 번호를 사용하면 AS 번호 고갈 문제 해결

현재 16비트와 32비트 AS 번호는 함께 사용되며, 대부분의 네트워크 장비와 BGP 소프트웨어는 32비트 AS 번호를 지원한다.

공인 AS 번호(Public AS Number) vs. 사설 AS 번호(Private AS Number)

AS 번호는 공인(인터넷에 연결된 AS) 과 사설(내부 네트워크에서만 사용) 로 구분된다.

1. 공인 AS 번호(Public AS Number)

  • 인터넷에서 공식적으로 사용되는 AS 번호
  • IANA 및 RIR(Regional Internet Registry) 를 통해 관리됨
  • ISP, 대기업, 데이터센터, 클라우드 사업자 등이 사용
  • BGP를 통해 글로벌 인터넷에 연결되는 네트워크에 할당됨

공인 AS 번호 범위

  • 1 ~ 64511 (16비트)
  • 65536 ~ 4199999999 (32비트)

2. 사설 AS 번호(Private AS Number)

  • 인터넷이 아닌 내부 네트워크(기업, 기관, 연구소 등)에서만 사용
  • 인터넷에서 사용되지 않으며, 외부로 라우팅되지 않음
  • NAT(Network Address Translation) 또는 BGP 설정을 통해 공인 AS 번호로 변환 가능

사설 AS 번호 범위

  • 64512 ~ 65534 (16비트)
  • 4200000000 ~ 4294967294 (32비트)

사설 AS 번호가 사용되는 경우

  • 기업 내부에서 BGP를 사용한 네트워크 연결
  • 데이터센터에서 고객 네트워크 분리 및 관리
  • 클라우드 서비스에서 가상 네트워크 간 연결

구분설명
AS 번호인터넷에서 네트워크를 식별하는 고유한 숫자
16비트 → 32비트 확장 이유인터넷 확장으로 AS 번호 부족 해결

AS 번호는 인터넷의 라우팅과 트래픽 관리에서 중요한 역할을 하며, 공인 AS 번호는 인터넷 서비스 제공(ISP) 및 기업에서 사용, 사설 AS 번호는 내부 네트워크 관리에 활용된다.
