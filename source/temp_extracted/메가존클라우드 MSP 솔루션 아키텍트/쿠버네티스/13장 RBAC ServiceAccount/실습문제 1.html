실습문제 1

ConfigMap + Secret 활용 실습

요구사항

  1. 다음 조건을 만족하는 ConfigMap을 생성하라.
KeyValue
APP_MODEproduction
LOG_LEVELinfo
  1. 다음 조건을 만족하는 Secret을 생성하라.
KeyValue
DB_USERadmin
DB_PASSWORD1234

※ Secret은 YAML 방식으로 생성하고, base64 인코딩하여 작성한다.

  1. 다음 조건을 만족하는 Pod를 생성하라.
  • 이미지: nginx
  • 환경변수로 ConfigMap 전체 주입
  • DB_PASSWORD만 Secret에서 개별 주입
  • Pod 이름: web-test
  1. Pod 내부에서 다음을 확인하라.
printenv | grep APP_MODE
printenv | grep DB_PASSWORD

실습문제 2

ServiceAccount / User RBAC 적용 실습

시나리오

상황

  • 개발팀 ServiceAccount는 Pod 조회만 가능해야 한다
  • 운영팀 User는 로그 조회까지 가능해야 한다

ServiceAccount 구성

요구사항

  1. dev-sa 라는 ServiceAccount 생성
  1. 다음 권한을 가진 Role 생성
  • pods → get, list
  1. RoleBinding으로 dev-sa에 연결
  1. 다음 명령으로 권한을 검증하라
kubectl auth can-i get pods --as system:serviceaccount:default:dev-sa
kubectl auth can-i get pods/log --as system:serviceaccount:default:dev-sa

예상 결과:

  • pods → yes
  • pods/log → no

User 권한 구성

요구사항

  1. 다음 권한을 가진 Role 생성
  • pods → get, list
  • pods/log → get
  1. RoleBinding 생성
  • User 이름: ops-user
  1. 다음 명령으로 확인
kubectl auth can-i get pods --as ops-user
kubectl auth can-i get pods/log --as ops-user
kubectl auth can-i create pods/exec --as ops-user

예상 결과:

  • pods → yes
  • pods/log → yes
  • pods/exec → no
